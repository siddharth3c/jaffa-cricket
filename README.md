# Jaffa · the daily delivery

A cricket take on the daily-dive format of krillion.io.

Seven cricket prompts a day, the same for everyone. Rarer answers score more and carry the ball further down the pitch. After the seventh ball the delivery reaches the batter: a long hop gets smashed for six, a yorker barely gets dug out.

Modes: daily delivery, archive, themed packs, unlimited nets, Cherry Bomb party (online rooms via PeerJS or one shared device), stats, friend challenge links.

Static site, no build step. Everything is stored in the player's browser.
